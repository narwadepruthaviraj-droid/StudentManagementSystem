# Student Management System

## Project Overview

Student Management System is a command-line based Java application developed to manage student records.

The application allows users to add, view, search, update, and delete student records. It also provides student statistics, grading, sorting, and file-based data persistence.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Calculate Average Marks
- Find Highest and Lowest Marks
- Display Student Grade
- Sort Students by Marks
- Sort Students by Name
- Save Student Data to File
- Load Student Data from File
- Input Validation
- Exception Handling

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- File Handling
- Exception Handling
- Java Collections and Comparator
- Command Line Interface
